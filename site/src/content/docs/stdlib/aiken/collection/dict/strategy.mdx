This module contains strategies used to transform [`Dict`](/stdlib/aiken/collection/dict/#Dict). You can safely ignore this module if you aren't using [`union_with`](/stdlib/aiken/collection/dict/#union_with) nor [`insert_with`](/stdlib/aiken/collection/dict/#insert_with).

## Types

### `DiscardValue<key, value>` {#DiscardValue}

A callback to discard a value at a given key

#### Alias

```aiken
DiscardValue<key, value> = fn() -> Pairs<key, value>
```

### `InsertStrategy<key, value>` {#InsertStrategy}

A strategy for inserting a value from a dictionary into another.

#### Alias

```aiken
InsertStrategy<key, value> = fn(
    key,
    value,
    KeepValue<key, value>,
    DiscardValue<key, value>,
  ) ->
    Pairs<key, value>
```

### `KeepValue<key, value>` {#KeepValue}

A callback to keep a combined value at a given key

#### Alias

```aiken
KeepValue<key, value> = fn(value) -> Pairs<key, value>
```

### `UnionStrategy<key, value>` {#UnionStrategy}

A strategy for combining two values in a dictionary that belong to the same key.

#### Alias

```aiken
UnionStrategy<key, value> = fn(
    key,
    value,
    value,
    KeepValue<key, value>,
    DiscardValue<key, value>,
  ) ->
    Pairs<key, value>
```

### `difference_if_non_zero` {#difference_if_non_zero}

```aiken
difference_if_non_zero() -> UnionStrategy<key, Int>
```

Keep the resulting difference only if it's non zero; otherwise discard the key entirely.

```aiken
fn(_key, left, right, keep, discard) {
  let value = left - right
  if value != 0 {
    keep(value)
  } else {
    discard()
  }
}
```

### `sum_if_non_zero` {#sum_if_non_zero}

```aiken
sum_if_non_zero() -> UnionStrategy<key, Int>
```

Combine values by taking their sum, only if it is non-null. If the
resulting sum is 0, discard the key/value entirely.

```aiken
fn(_key, left, right, keep, discard) {
  let value = left + right
  if value == 0 {
    discard()
  } else {
    keep(value)
  }
}
```
